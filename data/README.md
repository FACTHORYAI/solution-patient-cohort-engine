# Sample data

Every file below is synthetic: invented clinical notes and the rows extracted from them,
generated by [`generate_sample.py`](generate_sample.py) from sentence templates and small
clinical vocabularies. No real patient, note or record is used. Licence: CC0-1.0. The folder is
about 150 KB, far under the 5 MB per file and 20 MB per folder limits.

| File | What it is | Where it came from | Licence | Synthetic |
| --- | --- | --- | --- | --- |
| `notes.parquet` | 139 clinical notes for 48 patients, dated 2023-02 to 2025-08: note_id, subject_id, event_date, text, gender, date_of_birth | Generated by `generate_sample.py` | CC0-1.0 | yes |
| `posology.parquet` | Drug-usage relations per note (strength, frequency, route, duration, reason), with RxNorm codes and resolved drug names | Written by the generator from the same templates as the notes | CC0-1.0 | yes |
| `clinical_entities.parquet` | Symptoms, body parts, tests, procedures and conditions per note | Written by the generator from the same templates as the notes | CC0-1.0 | yes |
| `graph_nodes.parquet` | Knowledge-graph nodes (Patient, RxNorm, Drug, Symptom, Body_Part, Procedure, Test, Disease_Syndrome_Disorder), one row per node | Built from the three tables above by the `build_knowledge_graph` job | CC0-1.0 | yes |
| `graph_edges.parquet` | Knowledge-graph edges, one fact per row, with note evidence and character span | Built from the three tables above by the `build_knowledge_graph` job | CC0-1.0 | yes |

`posology` and `clinical_entities` are what a text model would return for each note. Here they
are exact by construction, because they come from the same templates as the notes; they are not
the output of a model. `tests/recorded_answers.json` replays them so the extraction jobs run
without a model.

The RxNorm codes are illustrative identifiers for the sample and are not verified against a
vocabulary. A production run resolves codes against a real drug vocabulary behind the text model.

To regenerate (the same seed always gives the same files):

```
uv run python data/generate_sample.py
```
